=== Other things learned the hard way ===
* The tree is NOT a git repo; back up every file before editing.
* `patch -p1` with the split diff headers (they read `diff --git b/X a/X`) applies
  changes BACKWARDS.  Verify both directions.
* Interrupted builds corrupt objects (`ld.lld: head.o: invalid symbol index`).
  Always `make clean` after a killed build.
* The OPLUS log partitions are `oplusreserve2` (256 MB), `logdump` (sde66),
  `logfs` (sde65).  Read with:
    adb shell su -c 'dd if=/dev/block/by-name/oplusreserve2 bs=1M count=256 \
      | strings -n 8 | grep -E "Booting Linux|#5[0-9] SMP"'
  If your build number never appears, the kernel died before its first printk.
